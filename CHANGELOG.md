# Changelog

## 1.0.0-beta.1 — Beta 1.0.0

- Dockable After Effects CEP panel built with JavaScript and ExtendScript.
- Standalone AE automation with OpenAI GPT, Anthropic Claude, and local Ollama providers. No Higgsfield dependency.
- Korean, English, and Simplified Chinese interface.
- Previewable plans for compositions, nulls, text, solids, shapes, adjustment layers, transforms, keyframes, parenting, and composition markers.
- Local plan validation and a single Undo group for each execution.
- Session-only API keys, request cancellation, and bounded request and plan sizes.
- Offline demo, per-user installers, dependency-free packaging, and automated mock tests.
- Initial beta: real After Effects and live model verification remain manual release checks.
